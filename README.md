# Bastketball

A blocky 3D basketball game made in Godot 4 (1 v 1 / 3 v 3, 1 or 2 players).

## Play in the browser
The playable game is in the `docs/` folder. To put it online with GitHub Pages:
**Settings -> Pages -> Build and deployment -> Deploy from a branch ->
`main` and `/docs` -> Save.** After a minute it is live at
`https://<your-name>.github.io/<repo-name>/`.

## Edit the game
Open `project.godot` in Godot 4.3 or newer.
